# Grid-Down Preparedness Brief

A 2–4 week household emergency-preparedness plan, sized for a family of four
(2 adults + 2 kids). Single-file HTML slide deck — open `index.html` or view the
published version.

**What it covers:** water, heat/light/cooking, food, comms/power/cash/meds, a
Phase 2 independent solar build, a "skip list," and a 4-step action plan.

**Numbers:** core ~$775 · Phase 1 ~$1,777 · all-in with solar ~$2,472.
Prices are street estimates and drift — treat them as starting points.

**Navigation:** arrow keys / space to advance, `P` to print, swipe on mobile.
